## Intro :

This mod enhances the vanilla villages by improving existing structure, making them feel more alive and engaging to explore.

Available:

- Plains Village
- Snow Village
- Savanna Village
- Desert Village
- Taiga Village

### Compatibility :

The mod is designed to ensure maximum compatibility. However, some mods may require their own compatibility pack to achieve perfect results. 
Overall, it should work with most mods, with the exception of a few unforeseen issues or bugs, of course.

Works perfectly with:
- Repurposed Structures
- ChoiceTheorem's Overhauled Village
- [Bountiful (Datapack Available CLICK HERE)](https://modrinth.com/datapack/better-villages-bountiful)
